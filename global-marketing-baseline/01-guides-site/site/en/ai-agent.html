What the STA-100 actually is

The STA-100 Workie is a desktop private AI agent appliance. It runs the OpenClaw agent runtime, executes a large language model locally, keeps a local vector index for retrieval over your documents, and exposes the agent workflow layer that connects to CRM, ERP, mail and internal APIs. Why organisations move to a private AI agent

  • Data sovereignty — prompts, documents and agent traces stay on site. This is the practical answer to GDPR, the EU AI Act, Indonesia's PDP Law and China's data localisation rules.
  • No seat pricing — one purchase per unit instead of a monthly per-user licence. Adding users does not add licence cost.
  • Works offline — no internet dependency, no external API call, no vendor-side data retention.
  • Agent workflows, not just chat — the appliance runs tool-calling agents that can read local documents and call internal systems.

Frequently asked questions

What is an AI agent?

An AI agent is software that plans multi-step work, calls tools such as CRM, databases and APIs, keeps memory between conversations, and can delegate to other agents. A cloud AI agent sends that data to the provider's servers; a private AI agent runs the same loop on hardware you control.

What is a private AI agent appliance?

A private AI agent appliance (also called an AI box or AI appliance) is a single device that runs large language model inference, document retrieval and agent workflows locally, with no cloud dependency and no per-seat subscription.

What is the difference between a private AI agent and ChatGPT Enterprise?

ChatGPT Enterprise runs in the vendor's cloud: prompts and files leave your network and the price scales per seat per month. A private AI agent appliance runs on local hardware, so data never leaves the premises and the cost is a one-time purchase per unit. The trade-off is that you own the hardware and the local model runs at local hardware speed.

Who should deploy a private AI agent?

Law firms, hospitals, banks, insurers, manufacturers, schools, government offices, MSPs and system integrators — any organisation whose data cannot leave the building, or whose country requires data sovereignty such as GDPR, the EU AI Act, Indonesia's PDP Law or China's data rules.

Does STRATRONIX STA-100 need an internet connection?

No. The STA-100 runs local LLM inference and can operate fully offline or on a private network. The install takes 8-10 minutes.
