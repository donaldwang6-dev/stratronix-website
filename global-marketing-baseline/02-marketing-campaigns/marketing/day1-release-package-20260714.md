**标题**：
[P] Anyone tried a pre-built appliance for running local LLMs at work? We shipped one, curious what folks think

**正文**：

Hey all — sharing something we've been working on in case it's useful or worth critiquing.

We built STRATRONIX STA-100, a small appliance (router-sized) for teams who want to run local LLMs without rolling their own setup.

**What's inside:**
- 4GB RAM + 32GB storage
- Wi-Fi + Gigabit Ethernet
- OpenClaw OS (a thin Linux layer)
- Web UI at `openclaw.local`
- Pre-installed: Ollama + Open WebUI
- Models supported: Qwen 2.5, LLaMA 3.1, Mistral, DeepSeek-V2

**Setup:**
1. Plug in power + ethernet
2. Open browser → `openclaw.local`
3. Pick your model
4. 30 seconds total

**Why we built it:**
Most "local LLM" tutorials assume you have a Linux sysadmin on staff. We talked to a lot of legal teams, hospitals, and manufacturers who want local AI but don't have a GPU cluster or a DevOps team. STRATRONIX is for them.

**What we'd love feedback on:**
- Is the hardware under/over-spec'd for 7B-13B quantized models?
- Should we add vLLM support out of the box?
- Anything else that would make it more useful for the r/LocalLLaMA crowd?

We have a 7-day free trial if you want to put hands on. Real device shipped, you keep it ($369) or send it back.

Not trying to sell here — genuinely curious what this community thinks about the appliance category.
