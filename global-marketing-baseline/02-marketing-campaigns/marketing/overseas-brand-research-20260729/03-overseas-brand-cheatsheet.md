## 🎯 每日内容公式（万能模板）

### LinkedIn 长文公式
```
Hook: 1 句反直觉事实
Context: 1 段背景
Story: 1 个真实故事
Lesson: 3-5 条要点
CTA: 1 个问题（引发评论）
```

### Twitter Thread 公式
```
Tweet 1: Hook（让人想读）
Tweet 2-9: 1 个要点 / Tweet
Tweet 10: 总结 + CTA
```

### YouTube 视频公式
```
0:00 Hook（3 秒抓住注意力）
0:15 问题陈述
1:00 解决方案介绍
5:00 实际演示
10:00 总结 + 链接
```

### Reddit 真实回复公式
```
1. 确认理解对方问题
2. 分享类似经验（不是 STRATRONIX）
3. 给具体建议
4. 末尾签名：我是 [名字]，[公司]，[品牌网站]
```
