STA-100 Workie · Matériel

Le Matériel Qui Alimente Votre Bureau IA

Workie est un agent IA dédié qui fonctionne 24h/24 sur le matériel STA-100, connecté à vos applications de messagerie préférées. Contrairement aux chatbots basés sur le cloud, Workie réside dans votre réseau local — vos données restent dans votre appareil et deviennent votre actif de données permanent.

  • ✓ Fonctionne dans WhatsApp / Telegram / WeChat / Slack / Feishu
  • ✓ Pas de téléchargement d'application — discutez simplement comme avec un collègue
  • ✓ Clés API Cloud Multi-LLM : Claude, GPT, Gemini, DeepSeek, Mistral, etc.
  • ✓ Mémoire locale — se souvient de vos projets et préférences
  • ✓ Accès système complet : email, calendrier, fichiers, terminal
  • ✓ Conforme RGPD et souveraineté des données
