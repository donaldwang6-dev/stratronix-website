STRATRONIX, 경량 사설 AI Agent 기기 STA-100 출시

STRATRONIX의 첫 경량 사설 AI Agent 기기 STA-100이 최종 테스트를 거쳐 정식 출시를 앞두고 있습니다!

주요 기능:

  • 🖥️ XFCE 안정적 OS — 가벼운 Linux 데스크탑, 서버급 안정성
  • ⚡ Octa-core ARM — 초저전력, 24시간 실행 시 월 ~15kWh
  • 🔧 내장 OpenClaw 프레임워크 — 즉시 사용 가능한 AI Agent 런타임
  • 🚀 간편 배포 — 20분 완료, IT 전문가 불필요
  • 🏠 광범위한 애플리케이션 — 교육, 의료, 소매, 홈 어시스턴트
