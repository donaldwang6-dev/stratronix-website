OpenClaw OS: Hệ Điều Hành AI Agent

Bởi STRATRONIX | Cập nhật 2026-07-14

OpenClaw là gì?

OpenClaw OS là hệ điều hành AI Agent nguồn mở powering STRATRONIX PAA. Được phát hành theo giấy phép BSD-3-Clause, OpenClaw là nền tảng cho triển khai AI Agent tự lưu trữ.

OpenClaw với AI Agents giống như Linux với máy chủ:

  • Linux → máy chủ (1991) → cách mạng
  • OpenClaw → AI Agents (2025) → cách mạng

Tính Năng OpenClaw

1. Hỗ Trợ Multi-LLM

OpenClaw hỗ trợ 10+ LLM có sẵn:

  • Llama 3.3 70B / 8B (Meta)
  • Qwen 2.5 72B (Alibaba)
  • Mistral 7B / 22B / Mixtral
  • DeepSeek V2 / R1
  • GLM-4 (Zhipu)
  • Aquila (BAAI)
  • Yi (01.AI)
  • InternLM (Shanghai AI Lab)
  • Các mô hình tự fine-tune của người dùng

2. 10 AI Agents Đã Xây Dựng Sẵn

  1. Sales Agent (tích hợp CRM)
  2. Customer Service Agent (24/7 đa ngôn ngữ)
  3. Legal Agent (xem xét hợp đồng)
  4. HR Agent (sàng lọc sơ yếu lý lịch)
  5. Finance Agent (OCR hóa đơn)
  6. Marketing Agent (nội dung đa ngôn ngữ)
  7. Code Agent (PR review)
  8. Research Agent (phân tích thị trường)
  9. Personal Assistant (lịch/email)
  10. Custom Agent (Python SDK)

3. RAG Engine

  • Vector database (Qdrant tích hợp)
  • Ingest tài liệu (PDF, DOCX, XLSX, MD, HTML)
  • Hỗ trợ multi-modal (văn bản + hình ảnh)
  • Tìm kiếm hybrid (vector + từ khóa)

4. Tương Thích MCP

OpenClaw triển khai Model Context Protocol (tiêu chuẩn của Anthropic), cho phép tương thích với hệ sinh thái MCP rộng hơn.
