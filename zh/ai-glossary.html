AI 智能体词典：PAA / Agent / RAG / LLM 等 50 个术语

作者：STRATRONIX 鼎图太易 | 2026-07-14 | 阅读时长 12 分钟

前言

2026 年 AI 行业术语爆炸式增长。一个 AI 入门者面对 PAA、Agent、RAG、LLM、MCP、Embedding 等术语往往一头雾水。

STRATRONIX 鼎图太易整理 50 个最常用术语，按字母顺序，做成这份一站式词典。

A

Agent（AI 智能体）

能自主完成任务的 AI 系统。可以调用工具、读取记忆、规划多步操作。STRATRONIX PAA 内置 10 个 Agent。

AGI（通用人工智能）

具备人类水平智能的 AI。目前未实现，仍是研究目标。

API（应用程序接口）

软件之间互相调用的标准方式。STRATRONIX PAA 提供 REST API 给第三方系统调用。

B

BERT

Google 2018 年发布的预训练语言模型，是早期大模型的代表。

BLEU Score

机器翻译评估指标。0-100 分，越高越好。

C

ChatGPT

OpenAI 推出的对话式 AI 产品。基于 GPT 系列模型。

Context Window（上下文窗口）

LLM 一次能处理的最大 token 数。Llama 3.3 70B 是 128k tokens（约 6 万字）。

D

DSL（Data Security Law，数据安全法）

中国 2021 年实施的数据安全法律。所有在华业务必须遵守。STRATRONIX PAA 默认合规。

E

Embedding（向量嵌入）

把文字转为数字向量的技术。STRATRONIX PAA 用 Embedding 实现 RAG。

F

Fine-tuning（微调）

用特定领域数据继续训练大模型。STRATRONIX PAA 支持用户微调模型到公司数据。

G

GPT（Generative Pre-trained Transformer）

OpenAI 的旗舰大模型系列。GPT-4 / GPT-4o 是当前版本。

Generative AI（生成式 AI）

能生成内容（文本、图像、代码）的 AI。LLM 是代表。

H

Hallucination（幻觉）

LLM 生成看似合理但实际错误的内容。RAG 可以缓解。

HIPAA（美国医疗数据保护法）

Health Insurance Portability and Accountability Act。医疗数据合规标准。STRATRONIX PAA 满足。

I

Inference（推理）

LLM 运行（生成输出）的过程。STRATRONIX PAA 在本地进行推理，不上传数据。

L

LLM（Large Language Model，大语言模型）

基于 Transformer 架构的大规模语言模型。代表：Llama 3.3 / GPT-4 / Qwen / Mistral。

LLaMA（Meta 大模型）

Meta 公司开源的大模型系列。STRATRONIX PAA 默认加载 Llama 3.3 70B。

LLM Ops

LLM 运营工具集。包括 RAG、Agent、监控、A/B 测试等。

M

MCP（Model Context Protocol）

Anthropic 2024 年提出的智能体协议。标准化 LLM 与外部工具通信。STRATRONIX PAA 兼容 MCP。

Multi-modal（多模态）

处理多种类型输入输出（文本、图像、音频、视频）的 AI 能力。STRATRONIX PAA 支持文本 + 图像。

O

On-Premise AI

本地部署的 AI 服务。STRATRONIX PAA 是典型 on-premise AI 方案。

Open Source LLM

开源大模型。包括 Llama / Qwen / Mistral / DeepSeek 等。STRATRONIX PAA 默认用开源。

OpenClaw

STRATRONIX 自研的 AI 智能体操作系统。基于 Linux，BSD-3-Clause 开源。

P

PAA（Private AI-Agent Appliance，私有 AI 智能体设备）

STRATRONIX 发明的术语。指一台专用硬件设备，本地运行多个 AI 智能体，强调「私有」（数据不出公司）和「设备」（即开即用）。

PIPL（个人信息保护法）

中国 2021 年实施的个人信息保护法律。STRATRONIX PAA 默认满足。

Privacy-First AI

把数据隐私放在第一位的 AI 架构。STRATRONIX PAA 是典型代表。

Prompt Engineering

优化输入给 LLM 的提示词以获得更好的输出。STRATRONIX PAA 提供提示词模板。

Q

Q* / Qwen

阿里巴巴开源的大模型系列。Qwen 2.5 是当前版本。

Quantization（量化）

把 LLM 的高精度权重（如 16-bit）降到低精度（如 4-bit）以减小体积。STRATRONIX PAA 默认用 Q4_K_M。

R

RAG（Retrieval-Augmented Generation，检索增强生成）

让 LLM 在回答前检索相关文档，提高准确性。STRATRONIX PAA 内置 RAG 引擎。

RLHF（Reinforcement Learning from Human Feedback）

用人类反馈训练 LLM 的方法。GPT-4 / Llama 3 都用 RLHF。

S

Self-Hosted AI

自托管 AI。数据完全在公司内部。STRATRONIX PAA 是入门级自托管 AI 方案。

STA-100

STRATRONIX 第一款 PAA 产品型号。¥1,999（中国）/ $369（海外）。

SoTA（State of the Art）

当前最先进水平。常用于形容某个模型。

SLA（Service Level Agreement）

服务水平协议。STRATRONIX PAA 提供 7×24 在线支持 + 2 年硬件质保。

T

Tokenizer / Token

LLM 处理文本的基本单位。1 个 token ≈ 0.75 个英文单词 / 1.5 个汉字。

Transformer

2017 年 Google 提出的神经网络架构，是所有现代 LLM 的基础。

TPM（Tokens Per Minute）

每分钟处理的 token 数。STRATRONIX PAA 约 1000+ TPM。

V

Vector Database（向量数据库）

存储和检索 Embedding 向量的数据库。STRATRONIX PAA 内置 Qdrant。

Vertex AI

Google Cloud 的 AI 平台。Stratonix PAA 可与之集成（可选）。

W

Weights（模型权重）

LLM 训练后的参数。开源 LLM 的权重公开可下载。STRATRONIX PAA 装载开源权重。

#

1U

服务器机架单位。1U = 44.45mm 高。STRATRONIX STA-100 是 1U 机架设备。

7B / 70B / 405B

LLM 参数数量。70B = 70 billion (700 亿) 参数。Llama 3.3 70B 是主流尺寸。
