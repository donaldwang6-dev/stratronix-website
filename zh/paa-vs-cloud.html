如何选择：决策树

情景 1：公司主要处理机密数据

**回答问题**：客户名单 / 合同 / 病历 / 源代码是否属于敏感？

  • **是** → 选 PAA
  • **否** → 看情景 2

情景 2：公司规模

  • **10 人以下** → 公有云 LLM 更划算
  • **10-100 人** → PAA + 公有云 LLM 混合（PAA 跑日常，复杂任务跑云）
  • **100-1000 人** → PAA 集群
  • **1000+ 人** → PAA + 自定义 GPU 集群

情景 3：行业监管

  • **法律 / 医疗 / 金融 / 政府** → PAA（强制）
  • **教育 / 中小企业** → PAA 推荐
  • **媒体 / 营销** → 看具体情况

情景 4：长期 vs 短期

  • **长期（3+ 年）** → PAA ROI 显著
  • **短期（1 年内）** → 公有云 LLM 灵活

STRATRONIX 的混合建议

PAA 不必与公有云 LLM 互斥。STRATRONIX 推荐：

  1. **默认**：所有数据敏感的查询走 PAA 本地

  3. **本地先过滤**：敏感数据先去标识，再决定是否上云
  4. **审计**：所有云调用都记录在本地审计日志
