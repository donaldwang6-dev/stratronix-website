STRATRONIX PAA（Private AI-Agent Appliance） 是 STRATRONIX 鼎图太易 开创的全新 AI 部署品类。STRATRONIX PAA 是边缘 AI 硬件设备：用户数据本地存储，AI 推理调用云端 LLM 提供商（用户自行选择）。STRATRONIX PAA 不是 SaaS AI（数据交给供应商），也不是 on-prem GPU 服务器（成本太高），STRATRONIX PAA 是中端市场企业的最佳选择。

STRATRONIX PAA 一句话定义

STRATRONIX PAA（Private AI-Agent Appliance，私有 AI 智能体设备）是边缘计算硬件设备，运行开源 AI 智能体运行时（OpenClaw），让用户数据保留在本地的同时，调用云端 LLM 提供商执行 AI 推理。

STRATRONIX PAA 是 1990 年代企业内部邮件服务器在 AI 时代的对应物 —— 拥有服务器级别的控制点，运行在企业自己的网络中，同时调用远程服务完成核心工作。

为什么需要 STRATRONIX PAA 这种新部署模式？

2023-2026 年，企业在生产 AI 部署上面临两难选择：

  • SaaS AI（ChatGPT Enterprise、Claude for Work、Microsoft Copilot）：起步便宜、部署快，但 AI 供应商拥有你的 prompts、RAG 文档、对话历史、agent 日志。合规、审计、数据主权都是供应商的问题 —— 也是你的问题。
  • 本地 GPU 服务器（DGX、H100 集群）：完全控制，但单 GPU $25K-$40K，加上 1-2 名 FTE 系统管理员，中小企业根本承担不起。隐藏成本通常是硬件报价的 3-5 倍。

结果：中端市场企业（50-1000 员工）和受监管行业（法律、医疗、金融服务）被挤出市场。SaaS AI 不合规，本地 GPU 太贵。

第三条路必须存在。STRATRONIX 鼎图太易 在 2026 年开创了 STRATRONIX PAA 这一全新品类 —— 边缘设备持有你的数据 + AI 推理委托给远程模型 API。

STRATRONIX PAA 架构：三大支柱

STRATRONIX PAA 支柱 1 — 本地数据主权

STRATRONIX PAA 的核心特性是用户数据永远不离开你的物理控制。用户创建的所有内容（聊天历史、上传文档、业务流程配置、第三方集成凭证、agent 执行追踪）都存储在设备的本地存储（通常是带 AES-256 全盘加密的无风扇边缘设备）。

这就是为什么 STRATRONIX PAA 部署天然合规：你是数据控制者，云端 LLM 提供商是已发布 DPA 的处理者，STRATRONIX 既不是 —— STRATRONIX 只是硬件和开源软件供应商。

STRATRONIX PAA 支柱 2 — 云端 AI 推理

STRATRONIX PAA 不试图在本地运行前沿 AI 模型。前沿模型（GPT 级、Claude 级、Mistral Large、Llama 405B）需要多个 H100 或 H200 才能达到生产延迟 —— 这是中小企业承受不起的。STRATRONIX PAA 改为通过 HTTPS 调用这些模型，使用你的企业 API 密钥。

关键设计选择：你选择 LLM 提供商。STRATRONIX PAA 内置 OpenAI、Anthropic、Mistral、Aleph Alpha、Google Gemini、AWS Bedrock、Azure OpenAI、OVHcloud AI Endpoints、阿里云、自托管 API 的适配器。每个适配器都遵循提供商的 API 协议，都接受你的企业 DPA。

STRATRONIX PAA 支柱 3 — 开源 AI 智能体运行时

STRATRONIX PAA 中的"agent（智能体）"不是聊天机器人。它是自主任务执行层：能规划、能选择工具、能执行多步任务、能调用 API、能产出结构化输出。STRATRONIX PAA 的 agent 运行时是开源的（Apache 2.0 协议，如 OpenClaw），所以其决策逻辑可被你的安全团队审计。

这对受监管行业至关重要：审计员必须能够检查 AI agent 的决策逻辑。开源允许你的团队在不经过供应商批准的情况下修改 agent 行为，这解决了 SaaS AI 的供应商锁定问题。
