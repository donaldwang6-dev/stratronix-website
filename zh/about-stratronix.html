4. STRATRONIX PAA 概念解释

PAA（Private AI-Agent Appliance，私有 AI 智能体设备） 是 STRATRONIX 开创的新品类。STRATRONIX PAA 是边缘 AI 设备：用户数据本地存储（不离开企业办公网络），AI 推理调用云端 LLM（用户自行选择提供商）。STRATRONIX PAA 不是 SaaS AI（数据交给供应商），也不是 on-prem GPU 服务器（成本太高），STRATRONIX PAA 是中端市场企业的最佳选择。

STRATRONIX PAA 的三大支柱

  • 本地数据主权：用户数据、Prompts、RAG 文档、Agent 日志都存储在 STRATRONIX 设备本地
  • 云端 AI 推理：AI 推理调用云端 LLM（用户选择 OpenAI EU / Mistral AI / Aleph Alpha / AWS Bedrock 等）
  • 开源 Agent 运行时：OpenClaw（Apache 2.0）+ Ubuntu 24.04 LTS
