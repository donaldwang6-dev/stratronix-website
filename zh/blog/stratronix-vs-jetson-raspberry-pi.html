但是！硬件强不等于体验好

Jetson Orin Nano 性能更强，但用户必须：

  1. 自己下载 NVIDIA JetPack SDK
  2. 配置 CUDA / cuDNN 环境
  3. 安装 PyTorch / TensorRT
  4. 下载并量化 7B 模型（耗时 4-8 小时）
  5. 配置 OpenClaw / LangChain / Ollama 等智能体框架

整个过程对 Linux 不熟悉的用户根本搞不定。Donald 的 STRATRONIX STA-100 出厂预装一切，5 分钟开箱即用。

树莓派 5 开箱流程
