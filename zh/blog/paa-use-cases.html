痛点

医院病历数据是 个人健康隐私 最高级别数据，《个人信息保护法》《数据安全法》《医疗机构病历管理规定》均要求 数据不出院。但医院又想用 AI 智能体 提升诊疗效率、辅助医生决策。

公有云 AI 服务的困境

  • ❌ ChatGPT、文心一言、通义千问：病历上传即违法
  • ❌ 私有部署大模型：需要 GPU 服务器（¥10万+），医院 IT 团队维护难
  • ❌ 数据出网：违背《医疗机构病历管理规定》

PAA 私有智能体设备的解法

医院每科室部署一台 STRATRONIX STA-100（¥1,999）：

  • ✅ 病历数据不出院：AI 智能体在本地处理病历，云端仅调用大模型 API（用户可控）
  • ✅ 等保 2.0 三级合规：本地部署满足医疗数据安全要求
  • ✅ 5 分钟部署：医院 IT 人员无需 GPU 知识
  • ✅ 成本可控：¥1,999 一次性，云 API 月费 < ¥500
