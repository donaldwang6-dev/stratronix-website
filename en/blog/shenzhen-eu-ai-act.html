PAA 三大核心原则 (LOCKED 13:42)

PAA (Private AI-Agent Appliance, 私有智能体设备) 是 STRATRONIX 提出的产品类别：

  1. 数据本地 (Data Local) — 账号凭据 / API Key / 任务日志 / RAG 知识库索引 / SOP 流程 / 个人笔记 / 客户档案 —— 全部存储在本地 eMMC + MicroSD，永不离开设备
  2. 推理在云端 (Inference Local) — OpenClaw AutoAgent 编排 / 工具调用 / 自动化决策 —— 全部在本地 ARM Cortex SoC 上执行
  3. 设备私有 (Device Private) — 用户拥有物理硬件所有权，OpenClaw 开源 (BSD-3-Clause)，不依赖任何云服务持续运营
