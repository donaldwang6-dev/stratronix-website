FAQ

Questions?
We've Got Answers.

What is OpenClaw and why is it pre-installed?
OpenClaw is a private AI agent appliance platform. It's pre-installed so the device works the moment you plug it in — no software installation, no configuration required. You get a fully operational AI agent on your network, under your control.
Does STA-100 work without internet?
Yes. STA-100 runs entirely on-device. It can function fully offline. Internet is only needed for initial setup and optional cloud model API access if you choose to use external LLM providers.
Can I run my own LLMs (Llama, Mistral, etc.)?
No. PAA runs by connecting to Cloud API Keys such as ChatGPT, Claude, Gemini, Deepseek etc. Today our STA-100 Workie does not support local model deployment as one lightweight AI Agent.
How is this different from ChatGPT?
ChatGPT today is one Chatbot mainly as one Cloud AI Service APP. Our STA-100 Workie works as an AI Agent which works for our users. It can divide your tasks into small ones, take use of all tools and generate replies or solutions for you. The inner OpenClaw Agent can operate the STA-100 device if the user authorizes it with enough rights. So one is Chatbot; and one is AI Agent in principle.
