## 一、产品基础问题

### Q1: STRATRONIX STA-100 是什么？
**A**: STRATRONIX 鼎图太易推出的 ¥1,999（$369 USD）私有 AI 智能体设备（PAA，Private AI-Agent Appliance）。简单说：本地 Mistral 7B 大模型 + OpenClaw OS 智能体系统 + 数据完全不出本地。5 分钟部署，开箱即用。

### Q2: STRATRONIX 跟 ChatGPT 有什么区别？
**A**: ChatGPT 数据上传 OpenAI 云端服务器，STRATRONIX 数据完全本地，**没有云端依赖**。STRATRONIX 兼容 OpenAI API，但本地优先。

### Q3: STRATRONIX 跟 Jetson / 树莓派 / NUC 有什么区别？
**A**: Jetson / 树莓派是开发板，需要您自己装系统 + AI 框架。STRATRONIX 是开箱即用产品，5 分钟部署，已经预装好一切。

### Q4: STRATRONIX 数据安全吗？合规吗？
**A**: 数据完全本地，符合 GDPR / HIPAA / 等保 2.0 / ISO 27001 框架。OpenClaw OS 自动安全更新，硬件 Root of Trust 启动校验，全磁盘加密 AES-256。

### Q5: $369 是不是太便宜了？是不是低端？
**A**: 不是低端，是极致的成本控制。我们选择 8 核 ARM 架构（不是 GPU），能效比高，工艺成熟。$369 是为普及私有 AI 而非高端发烧。

### Q6: 4GB RAM 够用吗？
**A**: 4GB LPDDR4 RAM 足够运行 INT4 量化的 7B 大模型（Mistral 7B / Qwen 2.5 7B / Llama 3 8B），日常写作、知识问答、代码辅助完全够用。如果需要 70B 大模型，请用 RTX 4090 工作站。

## 三、技术问题

### Q12: STRATRONIX 支持哪些 AI 大模型？
**A**: 预装 Mistral 7B（INT4 量化）。云 API 兼容 OpenAI / Claude / Anthropic / 通义千问 / 文心一言 / 智谱 / DeepSeek 等。

### Q13: 部署复杂吗？
**A**: 5 分钟：拆箱 → 插电 → 接网线 → 浏览器访问 → 登录。无需 Linux 知识。

### Q14: 没有网络能用吗？
**A**: 完全离线可用。基础 Mistral 7B 大模型本地运行，不需要联网。云 API 调用则需要联网。

### Q15: 支持中文吗？
**A**: 支持。预装 Mistral 7B 中文优化版。云 API 推荐 Qwen / 文心一言 / DeepSeek 中文最佳。

### Q16: 多用户可以用吗？
**A**: 可以。OpenClaw OS 支持 10+ 用户独立 docker 容器，每个用户独立知识库、对话记录、权限。

### Q17: 远程 OTA 更新支持多久？
**A**: 免费永久支持。OpenClaw OS 每月一次大版本更新，每周一次安全补丁。

### Q18: 故障了怎么保修？
**A**: 硬件 2 年免费保修（1 年标配 + 1 年延保）。软件 7×24 小时技术支持。故障 24 小时内远程诊断，硬件 5 个工作日内更换新机。

## 四、对比竞争品问题

### Q19: 跟 NVIDIA Jetson 比？
**A**: Jetson 性能略强（10 TOPS GPU）但 STRATRONIX 部署时间 5 分钟 vs Jetson 2-4 周。STRATRONIX 价格便宜 26%（$369 vs $499）。STRATRONIX 适合非技术用户。

### Q20: 跟专业级 GPU 工作站比？
**A**: RTX 4090 工作站能跑 70B 大模型，但价格 $3,500+，功耗 450W+。STRATRONIX 适合日常 AI 智能体场景，性价比高 10 倍。

### Q21: 跟 Hugging Face / Ollama / LangChain 比？
**A**: 这些是开源框架 / 平台，需要自己搭。STRATRONIX 是预装产品，一台机 = OpenClaw OS + Mistral 7B + AI 智能体框架 + Docker + RAG + API。

### Q22: 跟 Apple Mac mini / Windows NUC 比？
**A**: Mac mini ($599+) 和 NUC ($300-500) 是通用计算硬件。STRATRONIX 是专为本地大模型 AI 智能体优化（低功耗 ARM + 4GB RAM 精准配置 + OpenClaw OS 预装）。
