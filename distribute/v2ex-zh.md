"客户合同发到 OpenAI 服务器？你们想上新闻头条吗？"

## 我们的故事

2025 年初，公司讨论用 ChatGPT 提升效率。但立刻遇到三个问题：

1. **数据合规**：客户合同、源代码、病历数据，不能出海（《数据安全法》第 21 条）
2. **订阅费**：50 人公司，ChatGPT Team 一年 $15,000，每个月自动续费
3. **网络依赖**：偏远地区网络慢，访问海外 API 卡

我们试过自己用开源 LLM + Docker 部署，但运维成本极高。最后决定做一款**专门给企业用**的产品。

## 我们开源了什么

- **OpenClaw OS** (BSD-3-Clause): GitHub 开源
- **OpenClaw Agent SDK** (Python): 自定义 Agent 开发
- **OpenClaw MCP Server**: 兼容 Anthropic MCP 协议

## 我们没开源什么

- **STA-100 硬件设计**（商业化）
- **STRATRONIX 智能体商店**（运营）
- **企业级支持 SLA**（付费）

## 适用场景

✅ **适合**：
- 法律 / 医疗 / 金融 / 制造业 等需要保密的行业
- 团队 10+ 人每天高强度使用
- 客户数据敏感
- 长期想控制 AI 成本

❌ **不适合**：
- 个人临时查询（用免费 ChatGPT）
- 研究前沿模型（用 GPT-4o API）
